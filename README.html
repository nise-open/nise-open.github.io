ICSLab Public Site ​

Public VitePress application for https://www.nise.ac.cn.

This directory is part of the lab website monorepo. The GitHub repository icslab-open/icslab-open.github.io is only the static GitHub Pages deployment target.

Directory Layout ​

text
.
├─ .vitepress/
│  ├─ config/
│  │  ├─ index.ts              # VitePress i18n entry
│  │  ├─ shared.ts             # shared public config
│  │  ├─ en.ts                 # English nav/footer/site text
│  │  └─ zh.ts                 # Chinese nav/footer/site text
│  ├─ theme/
│  │  ├─ index.ts              # theme extension
│  │  └─ styles.css            # public theme CSS
│  └─ people.ts                # structured people page data
├─ en/                         # English pages
├─ zh/                         # Chinese pages
├─ public/                     # public static assets
├─ CNAME                       # www.nise.ac.cn
├─ LICENSE
└─ package.json

Commands ​

Run from repository root:

bash
bun run dev:public
bun run build:public
PUBLIC_DIST_DIR="apps/public/.vitepress/dist" bun run check:public

Run from this directory:

bash
bun run dev
bun run build
bun run preview

Content Rules ​

  • Maintain en/ and zh/ pages together unless a page is intentionally language-specific.
  • Put people data in .vitepress/people.ts; do not duplicate structured people content in Markdown.
  • Put public images and icons in public/.
  • Do not reference internal domains, private IPs, internal source paths, server paths, secrets, tokens, or private keys.
  • Do not import from private app sources or private shared packages.

Deployment ​

The public site is deployed by .gitea/workflows/deploy-public.yml from the monorepo root.

Deployment flow:

  1. Build this app with bun run build:public.
  2. Check public source and generated output with scripts/check-public-leak.sh.
  3. Copy only .vitepress/dist to icslab-open/icslab-open.github.io on the gh-pages branch.

CNAME is copied to the GitHub Pages repository root during deployment.

Pre-Push Check ​

bash
bun run build:public
PUBLIC_DIST_DIR="apps/public/.vitepress/dist" bun run check:public
git diff --check
